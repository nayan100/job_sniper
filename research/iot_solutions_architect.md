# Industrial IoT (IIoT) Solutions Architect: AI-Native Roles

The **Industrial IoT Solutions Architect** now acts as a "System Orchestrator," leveraging agentic AI to design entire factory-floor or smart-grid ecosystems.

## Role Overview
This role focuses on "Agentic IIoT" architectures where edge devices run local LLMs and negotiate tasks. Architects use **Gemini CLI**'s massive context window to ingest entire protocol specifications (MQTT, OPC-UA, Modbus) and **Claude CLI** to scaffold the implementation.

## Key AI-Driven Responsibilities
*   **Architectural Synthesis:** Using Gemini CLI to fetch real-time documentation and design C4 diagrams or Architecture Decision Records (ADRs).
*   **Protocol Engineering:** Generating complex data mapping logic and device drivers from PDF datasheets using AI-assisted prompts.
*   **System Integrity:** Designing "AI Trust Boundaries" and security guardrails for autonomous edge agents.

## Core Keywords in Job Postings
*   **"AI Prompting Mastery"**: Explicitly listed as a requirement for top-tier IIoT leadership roles.
*   **"Agentic Workflows"**: Designing systems where different IoT nodes use LLMs for decision-making.
*   **"Context Engineering"**: Managing the knowledge base that feeds into the AI-assisted design process.
